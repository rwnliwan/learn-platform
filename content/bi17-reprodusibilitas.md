# BI17: FAIR & Etika Genetik: Reprodusibilitas Bioinformatika

## Tujuan
- Menjelaskan krisis reproduksibilitas dan solusinya: workflow manager + container.
- Menerapkan prinsip FAIR pada data dan kode.
- Menjelaskan risiko privasi genetik (re-identifikasi) dan mitigasinya.
- Menyebutkan kerangka etika riset genomik (consent, return of results).

## Ringkasan
- Reprodusibilitas = workflow + container + versi + seed + data.
- Nextflow/Snakemake + Docker/Singularity = standar.
- FAIR: Findable, Accessible, Interoperable, Reusable.
- “Tersedia atas permintaan” = tidak tersedia.
- DNA selalu identifiable (puluhan SNP cukup).
- Data manusia → controlled access + etik + consent sejak awal.
- Keputusan rilis data satu arah — standar tertinggi di awal.
- Tata kelola genetik Indonesia: untuk Indonesia.
