# BI2: NCBI, Ensembl, UniProt: Perpustakaan Data Biologi

## Tujuan
- Menyebutkan peran tiap database utama: NCBI/ENA/DDBJ, Ensembl, UCSC, UniProt, PDB, GEO/SRA, TCGA, gnomAD, ClinVar.
- Membedakan database primer vs kurasi dan implikasinya untuk kepercayaan data.
- Menggunakan aksesi ID (bukan nama gen!) sebagai identifier stabil.
- Memilih database yang tepat untuk 5 pertanyaan riset tipikal.

## Ringkasan
- Primer (INSDC, SRA, GEO): arsip mentah; kurasi (Ensembl, UniProt, PDB): pengetahuan tepercaya.
- Selalu pakai ID stabil (aksesi), catat versi + tanggal.
- Interpretasi varian = gnomAD (frekuensi) + ClinVar (vonis) + bukti.
- rsID ≠ patogenik. Konflik ClinVar = kurasi manual.
- Waspadai bias populasi database global untuk pasien Indonesia.
- API/download untuk analisis serius; web untuk eksplorasi.
- Anotasi fungsional standar: posisi → protein → pathway → struktur.
- Fondasi untuk BI3 (format), BI6 (alignment), BI9 (RNA-seq).
