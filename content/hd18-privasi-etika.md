# HD18: k-Anonymity & Differential Privacy: Rahasia Pasien di Era Data

## Tujuan
- Menjelaskan serangan re-identifikasi via quasi-identifier (kasus nyata).
- Menerapkan k-anonymity, l-diversity dan mengenali keterbatasannya.
- Menjelaskan differential privacy (epsilon) secara intuitif + trade-off privasi-utilitas.
- Merancang tata kelola: IRB/komite etik, DUA, UU PDP, dan kapan memakai federated learning.

## Ringkasan
- Quasi-identifier dalam kombinasi = identifier (pelajaran Sweeney).
- k-anonymity: kerumunan minimal k; l-diversity: kerumunan beragam.
- Differential privacy: jaminan matematis via noise; epsilon kecil = privasi kuat.
- Federated learning: data diam, model jalan — tetap butuh DP + etik.
- Terapkan minimisasi agresif + segregasi akses.
- UU PDP: dasar hukum, persetujuan, hak subjek, keamanan.
- Sel kecil (<5) = bahaya — supresi/agregasi/DP.
- Dokumentasikan keputusan privasi seperti keputusan metode.
