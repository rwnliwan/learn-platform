# MR18: Validasi Model & Data Lineage

Tiga pilar validasi (conceptual soundness, ongoing monitoring, outcomes analysis) + data lineage (silsilah angka). Backtest != validasi.

- Validator independen; validasi berkelanjutan
- Override log = peta perbaikan yang ditulis pengguna
- Dokumentasikan kapan model gagal (label peringatan)
- Lineage: kualitas = perkalian — perbaiki titik bocor
- Anomali -> lineage dulu (80% = data)
