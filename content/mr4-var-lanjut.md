# MR4: VaR Lanjut — Filtered HS, Delta-Gamma, Component VaR

Tiga senjata lanjutan: Filtered HS (HS yang sadar rezim volatilitas), delta-gamma VaR (orde-2 untuk portofolio ber-opsi), component/marginal VaR (bedah kontribusi risiko per desk).

- Filtered HS: r*_t = (s_T/s_t)*r_t — pisahkan bentuk distribusi dari level vol
- Delta-gamma: dV ~ d*dS + 0.5*G*(dS)^2 — wajib untuk opsi
- Short gamma = jebakan volatilitas; delta kecil != aman
- Component VaR aditif sempurna; untuk alokasi limit/modal
- Manfaat diversifikasi tidak permanen — korelasi naik saat krisis
