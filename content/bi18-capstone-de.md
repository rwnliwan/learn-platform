# BI18: Capstone: End-to-End Differential Expression Nyata

## Tujuan
- Menjalankan alur DE end-to-end: QC → normalisasi → uji → koreksi → interpretasi.
- Menerapkan semua QC: batch (BI10), komposisi (BI9), anotasi (BI2).
- Menulis laporan reproduksibel (BI17) dengan keterbatasan jujur.
- Menilai kapan berhenti: bedakan temuan vs artefak.

## Ringkasan
- Alur profesional: QC → DE → interpretasi → laporan.
- Kunci desain sebelum lihat hasil (anti p-hacking).
- Metode benar: size factor, NB, FDR; kandidat dua dimensi.
- Interpretasi: pathway + literatur, bukan daftar gen.
- Catat setiap keputusan dengan alasan (jejak audit).
- Laporan 1 halaman: fakta + keterbatasan jujur + langkah lanjut.
- Terima review: standar kelulusan = definisi profesionalisme.
