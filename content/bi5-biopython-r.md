# BI5: Biopython & Bioconductor: Ngoding untuk Biologi

## Tujuan
- Menjelaskan peran Biopython (Seq, SeqIO, Entrez, pairwise2) dan Bioconductor (ekosistem R untuk genomik).
- Memparse FASTA/GenBank dan mengakses NCBI Entrez secara programatik.
- Melakukan operasi sekuens batch: komplemen, translasi, GC% (pola pikir vektorisasi).
- Memilih Python vs R sesuai tugas (dan menjelaskan kenapa lowongan minta keduanya).

## Ringkasan
- Biopython: Seq, SeqIO, Entrez — multitool Python untuk sekuens.
- Bioconductor: 2.300+ paket R; rumah statistik genomik (DESeq2).
- Python = engineering/pipeline/ML; R = statistik/visualisasi.
- Proyek nyata bilingual; fanatisme bahasa = tidak produktif.
- Waspadai 1-based (R) vs 0-based (Python).
- Bangun snippet library pribadi dari tiap lesson.
- Baca vignette sebelum forum; pahami tiap baris.
- Ngoding = leverage: tugas sehari manual = sejam dengan script.
