# MR5: Expected Shortfall & Ukuran Risiko Koheren

ES = ekspektasi kerugian bersyarat di luar ambang VaR: menjawab 'seberapa dalam jurangnya?'. ES koheren (4 aksioma); VaR gagal subadditivitas. Fondasi modal FRTB.

- ES_a = E[L | L > VaR_a]; selalu >= VaR
- Rasio ES/VaR = detektor ekor (~1.15 normal; >1.5 waspada)
- VaR bisa menghukum diversifikasi (contoh dua obligasi)
- FRTB memakai ES 97.5% untuk modal
- Praktik: laporkan keduanya — VaR untuk backtest, ES untuk kedalaman
