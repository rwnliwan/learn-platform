# MR19 (Capstone): VaR/ES Engine + Backtest + Stress Report

Proyek akhir track: bangun VaR engine 3 metode + ES, backtest ketiganya (Kupiec), stress test (historis/hipotetis/reverse), tulis laporan risiko 1 halaman.

- Milestone 1: engine 3 metode + ES + hipotesis tertulis dulu
- Milestone 2: backtest out-of-sample + pilih metode beralasan
- Milestone 3: 3 skenario stres yang mengubah keputusan
- Milestone 4: laporan 1 halaman (angka + aksi + keterbatasan jujur)
- Nilai = kejujuran metodologis, bukan 'semua hijau'
