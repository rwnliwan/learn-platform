# METODE — Misi Jembatan: Dana yang Melompat Rantai (misi-gabung-jembatan-lintas)

- **Sumber data (a) — slice nyata:** BitcoinHeist Ransomware Address Dataset, UCI Machine Learning Repository (https://doi.org/10.24432/C5BG8V), lisensi **CC BY 4.0** (atribusi: dataset oleh penulis BitcoinHeist via UCI ML Repository; dipakai dan diadaptasi untuk misi ini). Berkas `BitcoinHeistData.csv` diunduh dari arsip UCI pada 2026-10-15.
- **Slice:** 320 baris (120 berlabel `white`, 200 dari famili ransomware: paduaCryptoWall, montrealCryptoLocker, princetonCerber, princetonLocky, montrealCryptXXX, dll.), diambil dengan seed 42 dari 43.573 baris pertama arsip. Kolom asli dipertahankan: `address,year,day,length,weight,count,looped,neighbors,income,label`.
- **Kolom turunan `pola_mixing`:** dihitung dari fitur `length` (didokumentasikan penulis dataset sebagai pengukur *mixing rounds*: transaksi menerima & mendistribusikan jumlah serupa dalam beberapa putaran dengan alamat baru). Ambang dari slice ini: `mixing-rendah` (length < 12), `mixing-sedang` (12–59), `mixing-tinggi` (≥ 60) — persentil 50/75 slice.
- **Sumber data (b) — sintetis:** `bridge_tx.csv` (222 baris) dibuat 100% sintetis dengan seed 42: 6 jalur hop lengkap (2–4 hop, 3–5 rantai, jeda antar-hop 3–9 menit, fee 0,5–1,5% per hop), 2 decoy (jeda 45 menit; anjlok jumlah 20%), 200 transaksi latar acak. Kolom: `tx_id,rantai_asal,rantai_tujuan,jumlah,timestamp,alamat`. Tidak ada dana, alamat, atau entitas nyata.
- **Sumber data (c) — sintetis:** `watchlist.csv` (12 baris, kolom `alamat,label,sumber`): daftar simulasi contoh entitas sanksi — **bukan OFAC/SDN atau daftar sanksi asli mana pun**; 2 alamat di antaranya dipakai sebagai alamat akhir jalur DANA-02 dan DANA-05. Kolom `sumber` selalu bernilai `SIMULASI`.
- **Tanggal tangkapan:** 2026-10-15. Ukuran snapshot: ~55 KB (< 5 MB).
- **Batas jujur:** label `pola_mixing` adalah turunan misi dari satu fitur, bukan label ground-truth pencucian uang; dataset bridge & watchlist sintetis penuh sehingga "temuan" misi ini adalah latihan pola, bukan tuduhan terhadap pihak nyata; watchlist simulasi tidak boleh dipakai untuk keputusan sanksi sungguhan.
