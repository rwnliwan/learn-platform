# METODE — Misi Jejak Lapis: Fiat → Rantai → Fiat (misi-gabung-jejak-lapis)

- **Sumber data (berlisensi jelas):**
  - `alamat_label.csv` — slice 300 alamat dari **Bitcoin Heist Ransomware Address Dataset**, UCI Machine Learning Repository (https://doi.org/10.24432/C5BG8V), dilisensikan **CC BY 4.0** (Creative Commons Attribution 4.0 International — boleh dibagikan & diadaptasi dengan atribusi). Atribusi: Akcora, Gel, Kantarcioglu; via UCI ML Repository. Slice diambil 2026-10-15 dari `BitcoinHeistData.csv` (2.916.697 baris): 236 alamat `white` (reservoir sampling, seed 42) + 64 alamat dua keluarga ransomware (`montrealCryptoLocker`, `montrealCryptXXX`), dideduplikasi per alamat (satu baris per alamat; bila satu alamat muncul di beberapa tahun, baris dengan mixing tertinggi dipertahankan). Kolom dipertahankan apa adanya dari sumber: `address,year,day,length,weight,count,looped,neighbors,income,label`.
  - `onramp.csv` — **SINTETIS** (seed 42): 120 setoran tunai fiktif, Juni 2026. 10 nasabah fiktif (N001–N010) melakukan 96 setoran terstruktur Rp92–99,5 juta (tepat di bawah ambang monitoring internal Rp100 juta); 8 di antaranya terhubung ke dompet W001–W008 dan alamat on-chain dari slice di atas; 12 nasabah fiktif lain sebagai pembanding wajar.
  - `offramp.csv` — **SINTETIS** (seed 42): 120 penarikan fiktif; 24 di antaranya penarikan dari W001–W008 (94–98% dari total setoran, jeda 5–21 hari), sisanya noise dari dompet lain.
  - `watchlist.csv` — **SINTETIS, dinyatakan simulasi**: 12 alamat contoh untuk latihan screening sanksi; 2 di antaranya (CONTOH-SIM-01/02) sengaja sama dengan alamat jalur W003/W007 agar latihan join menemukan hasil. **BUKAN daftar OFAC/SDN asli** — tidak boleh dipakai untuk keputusan kepatuhan nyata.
- **Metode:** mixing_rounds per alamat = (count ≥ 50) + (neighbors ≥ 25) + (looped ≥ 1); skor layering per dompet S = h + 2m + floor(d/7) dengan h = jumlah hop (3 untuk jalur lengkap), m = mixing maksimum, d = jeda hari setor→tarik; jalur lengkap = dompet dengan ≥1 setoran DAN ≥1 penarikan.
- **Seed:** 42 (semua bagian sintetis). **Tanggal tangkapan:** 2026-10-15. **Ukuran:** 43052 byte (< 5 MB).
- **Batas jujur:** label ransomware pada slice adalah label dataset penelitian (2011–2018), dipakai di sini hanya sebagai *proxy pola mixing*, bukan vonis bahwa alamat itu milik penjahat; nama nasabah/cabang/bank semuanya fiktif; watchlist adalah simulasi dan tidak memiliki kekuatan hukum apa pun.
