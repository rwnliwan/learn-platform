# AUDIT UX PENGGUNA BARU — Learn Platform (situs live)
**Tanggal:** 2026-10-16 · **Metode:** browser audit read-only, sudut pandang pengguna baru, tanpa login.
**Skor entry-point publik: 4/10**

## Temuan utama
Auditor masuk dari root https://learn-platform-cyo.pages.dev — yang tampil adalah indeks LEGACY v1, BUKAN v2. Tidak ada tautan/nav dari root menuju permukaan v2 (/v2 tidak terdiscover dari pintu depan). Indeks publik menampilkan ±295 kartu (±246 judul benar + 48 kartu rusak + 1 placeholder), sementara isi v2 sebenarnya 607 lesson / 25 track.

## Friction points (bukti URL)
1. `/` — daftar datar ±295 kartu di bawah satu heading "Daftar Materi": tanpa header track, tanpa search/filter/sort.
2. `/` — ±48 kartu berjudul label sumbu chart, bukan nama lesson: "Share suara Roosevelt (%)", "θ (proporsi)", "Tahun" (4 kartu identik), "%", "DPD (hari)", "Error", "Rp triliun". Contoh: kartu "Share suara Roosevelt (%)" → /learn/a21-sampling-bias (lesson-nya ada, judulnya gagal diekstrak).
3. `/` → `/learn/hello` — halaman placeholder dev terpublikasi berisi catatan internal ("Foundation Status: ✅ Next.js + Cloudflare Pages, ✅ Design System v2, ✅ Neon PostgreSQL, ⏳ Content pipeline").
4. `/` — landing tanpa value proposition: H1 "Selamat Datang" + satu tagline generik; tanpa CTA, tanpa "mulai dari mana", tanpa jalur role/karier, tanpa penjelasan elemen interaktif.
5. `/` — kode track (A, B, BI, C, CR, D, DM, FR, HD, MR, PM-A/B/C/D, MK) tanpa nama/deskripsi/urutan rekomendasi; pengguna baru tidak tahu mana Foundation.
6. `/` — tanpa chrome situs: tidak ada navbar, tidak ada footer (about/contact/privacy), /sitemap.xml → 404 berbahasa Inggris ("This page could not be found.") — inkonsisten dengan situs berbahasa Indonesia. robots.txt hanya boilerplate Cloudflare.
7. `/learn/a11-tipe-data-skala` — rendering markdown rusak: tabel tampil sebagai teks pipa mentah "| Skala | Urutan | …", "---" tampil literal, asterisk mentah, blok jawaban Quiz 1 menampilkan tag <details>/<summary> mentah.
8. `/learn/a11-tipe-data-skala` — template lesson inkonsisten: tanpa metadata/TOC/prev-next (bandingkan A2.1 yang punya "45–60 menit • 2 lab interaktif • 6 quiz • 1 mini-case" + TOC + prev/next). "Next: A1.2" di A1.1 tampil sebagai teks biasa, tidak bisa diklik.
9. `/learn/a11-tipe-data-skala` — spoiler quiz inkonsisten: jawaban Quiz 1 terlipat <details>, jawaban Quiz 2/3 tampil sebagai teks terbuka.
10. `/` — progres tidak terlihat: tombol "Tandai Selesai ✓" ada di lesson, tapi kartu di indeks tidak menunjukkan status selesai/progress bar/"lanjutkan belajar".
11. `/` — kartu tanpa metadata (durasi, level, punya lab/quiz) untuk membantu memilih.
12. Kunjungan pertama `/` hang ±78 detik sebelum gagal; retry ±2,5 detik berhasil — flakiness cold start.
13. Inkonsistensi bahasa: brand Inggris "LEARN PLATFORM" vs isi Indonesia; halaman 404 full Inggris.
14. Konvensi judul kartu inkonsisten antar-track ("A1.1: …" vs "B1 — Probabilitas: Peluang: …" dengan kolon ganda & fragmen em-dash).

## 5 perbaikan berdampak terbesar (tanpa mengubah isi lesson)
1. Kelompokkan indeks per track dengan header bernama + deskripsi + urutan mulai yang direkomendasikan + kartu "Mulai dari sini".
2. Perbaiki bug ekstraksi judul (48 kartu) — fallback ke judul frontmatter/slug — dan hapus/redirect /learn/hello dari indeks.
3. Hero landing sungguhan: value proposition satu kalimat (lab, quiz, chart interaktif), 2–3 jalur audiens, CTA "coba 1 lesson".
4. Chrome minimal: navbar + footer; 404 berbahasa Indonesia; sitemap.
5. Search/filter indeks + metadata per kartu (durasi, level, badge lab/quiz); samakan template lesson (metadata, TOC, prev/next); perbaiki renderer markdown tabel/details di halaman legacy.

## Kesan 60 detik pertama (simpulan auditor)
Pengguna paham ini situs belajar gratis berbahasa Indonesia, tapi tidak paham kode track, mulai dari mana, atau apa "interaktif"-nya. Kesan: proyek sampingan individu berbakat, bukan produk komersial. Perilaku paling mungkin: scroll, klik A1.1, kena teks markdown mentah, kembali, lalu pergi/mem-bookmark satu lesson — tanpa jalur, tanpa progres, tanpa alasan kembali. 48 lesson berjudul rusak praktis tidak terdiscover.

## Implikasi untuk Gelombang A
"Mulai dari Sini" di dalam /v2 tidak memperbaiki pintu depan publik. Perlu keputusan Septian: root domain diarahkan ke v2 (redirect atau landing v2) vs root legacy dipertahankan. Halaman /learn/* lama tetap bisa hidup bila URL-nya dibuka langsung.
